# AirNut Sport Home Assistant 整合

這是一個非官方的 Home Assistant 自訂整合，透過 Bluetooth Low Energy（BLE）讀取 AirNut Sport 的感測資料。

本專案是為了保存原始成果，並針對新版 Home Assistant 做相容性改寫；並非 AirNut 或 Moji 官方專案。

![AirNut Sport 圖示](custom_components/airnut_sport/brand/icon.png)

## 功能

- 溫度
- 濕度
- PM2.5
- 電池電量
- BLE 自動發現或手動輸入 MAC 位址
- 手動選擇藍牙設備時，名稱包含 `AirNut` 或 `AirNuts` 的設備會優先顯示
- 可調整白天輪詢間隔（10 秒至 1 小時）與斷線延遲
- 可設定夜間時段，夜間完全停止輪詢，讓螢幕自然休眠

## 安裝

將 `custom_components/airnut_sport` 整個資料夾複製到 Home Assistant 的 `custom_components` 目錄，重新啟動 Home Assistant，然後到：

**設定 → 裝置與服務 → 新增整合 → AirNut Sport**

Home Assistant 必須具備下列其中一項：

- 主機內建或外接的 Bluetooth
- ESP32 Bluetooth Proxy

新增設備時，請先按下裝置背面的實體按鍵，讓 AirNut Sport 螢幕亮起並開始廣播。也可以選擇手動輸入 MAC 位址。

## 建議設定

根據原始使用說明：

- 白天輪詢間隔可由使用者自行設定，範圍為 10 秒至 1 小時。日常使用可考慮 300～600 秒。
- 斷線延遲不要低於 1 秒。

整合的選項頁也提供夜間設定：在指定時段內會完全停止 BLE 輪詢，讓裝置依自己的韌體計時器變暗或關閉背光；夜間結束時會恢復輪詢，下一次 BLE 讀取可能再次喚醒螢幕。開始與結束時間都設為 `00:00` 即停用夜間模式；也支援跨午夜設定，例如 `22:00` 到 `07:00`。這是停止輪詢，不是已確認的關閉螢幕命令。若裝置已完全進入藍牙休眠，恢復時可能仍需要按背面實體按鍵。

如果裝置不插電，螢幕大約 3 分鐘後可能自動熄滅，並進入藍牙休眠。輪詢間隔設在 120 秒以內，有機會在自動休眠前重新連線並維持裝置運作，但會增加耗電量。

長時間插電可能使機身發熱，造成溫度與濕度讀值逐漸偏高；這點和其他帶螢幕的空氣品質裝置類似。

## 我們的改寫

為了相容 Home Assistant 2026.10.1，本專案做了以下修正：

- 更新 Options Flow API，修正設定頁出現 `Invalid handler specified` 或 HTTP 500 的問題。
- 將 BLE 通知停止、延遲與斷線改為可等待且有順序的清理流程。
- 增加每台設備的更新鎖，避免重疊輪詢產生多個 BLE 連線。
- 增加封包格式檢查與診斷記錄。
- 只將可連線的 BLE 設備列入自動發現。
- 增加白天輪詢間隔與斷線延遲的安全範圍檢查。
- 根據實測 BLE 讀取會喚醒螢幕，增加可排程的夜間停止輪詢功能。
- 將第一次資料更新放到背景執行，避免設備暫時不可用時阻塞實體建立。

原始整合使用的 BLE 讀取命令與資料格式仍然保留；本專案沒有宣稱重新發現 AirNut 的全新協定。

## BLE 協定摘要

- 資料特徵 UUID：`f000c0e1-0451-4000-b000-000000000000`
- 讀取命令：`AA AA 6D 55 55`
- 回應標頭：`AA AA 6D`

目前整合是唯讀的，尚未確認可以透過 BLE 遠端關閉螢幕的命令。裝置自然休眠與背面實體按鍵喚醒，不等同於已經找到可控制螢幕的協定。

## 安全注意事項

- 不要替鼓包、破損或狀態不明的鋰電池充電，也不要重新裝回設備。
- 這是非官方整合，使用者需自行承擔風險。
- 目前原始程式碼授權未知；本專案沒有替原始程式碼新增授權聲明。
